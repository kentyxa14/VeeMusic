# 🎵 VeeMusic

**VeeMusic** — это современная музыкальная платформа, позволяющая слушать музыку напрямую из открытых Telegram-каналов.

Этот репозиторий является официальной информационной и юридической страницей проекта VeeMusic на GitHub. Здесь публикуются официальные документы платформы и готовые сборки приложений. Исходный код самого проекта является закрытым (проприетарным).
